PARROTHIT ROUND ANIMATED HEADER LOGO PATCH

INSTALLATION
1. Extract this ZIP.
2. Open the Parrothit-main folder inside it.
3. Merge its contents into the root of your existing Parrothit-main website project and overwrite when prompted.
4. Deploy the website.
