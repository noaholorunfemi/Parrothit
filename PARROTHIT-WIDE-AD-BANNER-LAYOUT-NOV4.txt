PARROTHIT — WIDE AD BANNER LAYOUT UPDATE
Date: 4 November 2026

WHAT CHANGED
- Replaced the old three-card bottom-of-page ad wrapper in the public rendering layer with three separate wide horizontal banner placements.
- Fixed visual templates by slot:
  Ad Card 1 (position 1): News Style (green/white newsroom treatment).
  Ad Card 2 (position 2): Business Professional (clean professional treatment).
  Ad Card 3 (position 3): Colourful Promotion (yellow/red promotional treatment).
- Distributed the three banners through the page content: homepage, category/news pages, article pages, and other public pages handled by the PARROTHIT content runtime.
- Added responsive banner dimensions and a compact mobile layout.
- Updated admin per-page advertising manager headings so administrators can identify each slot's template.
- Updated public script cache versions so deployed browsers request the new rendering scripts.

DATA AND ADMINISTRATOR CONTROLS
- Existing advertisement records and assigned position/page values are preserved.
- Existing advertiser inquiries, campaign records, branding uploads, payments, and storage assets are not deleted or migrated by this display-only update.
- Existing per-page advertisement manager controls remain in place.
- The old bottom display wrapper is removed from rendering; no database records are deleted.
- No SQL migration is required for this layout-only update.

DEPLOYMENT
Option 1: Deploy the full project ZIP, replacing the site's project files with this version.
Option 2: Extract the patch ZIP into the repository/project root, preserving its folder paths, overwrite the included files, then deploy.

6. Confirm existing ad images, click-through links, and assigned page/position data still appear.
