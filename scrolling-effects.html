Important: enable public reading of this one setting

Supabase protects site settings by default. To let visitors receive this design without exposing other settings, run the included supabase/scroll-effects-policy.sql once in Supabase → SQL Editor. This grants public read access only to the scroll_effects row; only signed-in admins can save changes.

After saving, open the live site in a private/incognito tab and refresh. If the policy has not been run, the site will safely use the built-in default instead.
