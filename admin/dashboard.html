Role policy

  • Owner / Admin 1: can manage approved admin accounts.
  • Admin 2–4: can manage newsroom content but cannot add/remove admins.
  • Maximum four active administrators, including the Owner.
  • Require verified email, secure password reset and server-side role checks.
