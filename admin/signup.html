Administrator registration

Restricted: Public visitors cannot register as administrators. Admin 1 (Owner) must authorize administrator accounts. Maximum: four administrators total.

To prevent unauthorized access, this page does not create admin accounts by itself. First configure Supabase, establish the Owner account using the secure setup instructions, then use the owner-only admin management feature.

Account details for each approved administrator should include a display name, unique username, email and a strong password. Password recovery is available from the forgot-password page.
