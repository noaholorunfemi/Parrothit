3. Draft and publish workflow

  1. Run discovery to collect recent links from enabled feeds.
  2. Check the headline, publisher, and source URL before creating a draft.
  3. Retrieve Source Text — FREE attempts to extract readable text from the original webpage. If the publisher blocks access or only exposes a teaser, the draft will say so and fall back to available feed text. Treat retrieved text as editorial reference; check reuse rights and do not publish it verbatim without permission.
  4. Create Original Detailed Report — AI asks the configured AI provider to write a detailed, paraphrased report (target about 900–1,300 words) from available source material. It requires AI credits and must not invent details if the source is too short.
  5. Open Article Editor, verify facts, rewrite/expand as needed, and explicitly select Approve & publish only when ready. Drafts remain In Review until you do so.

If AI credits are exhausted, source-text retrieval remains available. Never place service-role or AI API keys in public files. This page does not configure scheduled publishing.
