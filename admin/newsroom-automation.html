3. Draft and publish workflow

  1. Run discovery to collect recent links from enabled feeds.
  2. Check the headline, publisher, and source URL before creating a draft.
  3. Create Manual Draft — FREE uses the headline and available RSS summary without calling an AI provider. It is a working draft, not a verified finished article.
  4. Create AI Draft — OPTIONAL uses the configured AI provider and may require paid credits.
  5. Open Article Editor, verify facts, rewrite/expand as needed, and explicitly select Approve & publish only when ready. Drafts remain In Review until you do so.

If AI credits are exhausted, manual drafting remains available. Never place service-role or AI API keys in public files. This page does not configure scheduled publishing.
