3. Draft and publish workflow

  1. Run discovery to collect recent links from enabled feeds.
  2. Check the headline, publisher, and source URL before creating a draft.
  3. Retrieve Source Text — FREE attempts to extract readable text from the original webpage. If the publisher blocks access or only exposes a teaser, the draft will say so and fall back to available feed text. Treat retrieved text as editorial reference; check reuse rights and do not publish it verbatim without permission.
  4. Create Original Detailed Report — AI asks the configured AI provider to write a detailed, paraphrased report (target about 900–1,300 words) from available source material. It requires AI credits and must not invent details if the source is too short.
  5. Open the destination selected above. In the Category Card 1–6 manager, review and edit the complete article, approve it, then choose a category and card position. In the existing Article Editor, continue using its normal article workflow.

If AI credits are exhausted, source-text retrieval remains available. Never place service-role or AI API keys in public files. This page does not configure scheduled publishing.

＋ How to add more AI services (unlimited IDs)

The newsroom now has a hard maximum of 32 profiles total: your existing OpenAI and Groq plus 30 additional profiles. These include Gemini, OpenRouter, Mistral, Cloudflare Workers AI, Cohere, NVIDIA NIM, SambaNova, Z.ai, Hugging Face, Cerebras and model-specific profiles for selected providers. They appear below as Not configured until you add credentials and a model. Create or update one secret in Supabase Dashboard → Edge Functions → Secrets named NEWSROOM_AI_PROVIDERS_JSON. Keep your existing OPENAI and GROQ entries, then add only the providers you want to activate.

NEWSROOM_AI_PROVIDERS_JSON
{
  "OPENAI": {
    "name": "OpenAI",
    "api_key": "your-openai-secret-key",
    "api_url": "https://api.openai.com/v1/chat/completions",
    "model": "your-openai-model"
  },
  "GROQ": {
    "name": "Groq",
    "api_key": "your-groq-secret-key",
    "api_url": "https://your-groq-chat-completions-endpoint",
    "model": "your-groq-model"
  }
}

Provider setup: For each service you want to use, add its unique ID to this JSON secret with name, api_key, api_url and model. The 30 additional profiles are already listed in the provider panel. Model-specific profiles inherit their parent provider API key and endpoint, but each needs a valid model name. Cloudflare Workers AI reuses the existing Cloudflare token and account ID secrets when named CLOUDFLARE_API_TOKEN (or CLOUDFLARE_API_KEY / CF_API_TOKEN) and CLOUDFLARE_ACCOUNT_ID (or CF_ACCOUNT_ID); alternatively provide its API key and account-specific API URL in the JSON secret. Select a model supported by your provider's account; model names and free quotas can change. Some services offer free tiers while others may provide limited trial access or require billing. Save the secret, tap Refresh provider status, choose a configured service, then tap Save selected AI service. Existing individual NEWSROOM_AI_PROVIDER__* and legacy NEWSROOM_AI_1…NEWSROOM_AI_6… / NEWSROOM_AI_API_KEY secrets remain supported. All providers must expose OpenAI-compatible Chat Completions at the configured endpoint.

Configure at least one service before creating AI drafts. Free source-text retrieval does not require an API.
