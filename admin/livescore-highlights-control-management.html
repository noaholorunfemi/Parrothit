Automatic Playlist Finder & Embedding Checker

Searches YouTube for direct playlist candidates for the 50 presets. For each candidate, it checks up to 50 first public playlist items in the current playlist order using YouTube's embeddable status. Only candidates whose entire sample is marked embeddable and whose publisher title has at least a 50% name match can be added as inactive stations. Admin 1 must still review the publisher.

Requires the server-side YOUTUBE_DATA_API_KEY secret and the verifier Edge Function. The API's embeddable flag is only a screening step: content claims, regional/age rules, and later publisher changes can still prevent playback. The final YouTube IFrame preview is mandatory before activation.
